This is a program that detects a 1.6V signal coming from a former speaker toy with a giant, red button on it that plays whatever you've recorded. 

We removed the speaker, and captured the signal from the element. Now, when the button is pressed, the microcontroller catches the signal that used to go to the speaker in the toy, and instead actuates a servo that drops candy down a shoot for halloween. 

The code and electronics work well from this project. The hopper holding the candy gets jammed. Future iterations will include a constantly, slowly spinning agitation rod in the hopper.
